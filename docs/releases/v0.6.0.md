# Ziki 0.6.0 — Paper & Ink

## English

- A refreshed native settings window with a warm paper-and-ink palette, dark-mode support, clearer page hierarchy, and a resizable layout.
- The same ink-brush Z now appears on the website, app icon, settings pages, and idle menu bar.
- A clearer start page groups the Fn shortcut, permissions, and model configuration. About introduces the Boya and Ziqi story behind Ziki.
- Window titles follow the selected page. Use Command–1 through Command–6 to switch pages.
- History adds result counts and copy feedback; existing search, deletion confirmation, and local retention are preserved.
- Menu copy is consistent with the Chinese settings UI. Existing dictation, API configuration, mute behavior, privacy choices, and updater safeguards remain in place.

This is an Apple Silicon, self-signed preview, not Apple-notarized. The production bundle ID, credential service, storage paths, and signing certificate remain unchanged. No subscription or cloud account service is included.

## 简体中文

- 设置窗口换上纸白与墨色的视觉风格，支持深色模式和窗口缩放，页面层次更清楚。
- 官网、应用图标、设置面板和空闲状态的菜单栏统一为水墨 Z。
- 开始页集中展示 Fn 快捷键、权限与模型配置；关于页加入伯牙子期的品牌故事。
- 修复切换页面后窗口标题未同步的问题，支持 Command–1 至 Command–6 切换页面。
- 历史页新增结果计数与复制反馈，保留搜索、清空确认和本地留存规则。
- 菜单文案与中文设置面板统一；听写链路、API 配置、录音静音、隐私选项与更新校验保持不变。

此版本仍为 Apple Silicon 自签名预览版，尚未经 Apple 公证。正式版 Bundle ID、凭据服务、数据路径和签名证书未变，不包含订阅或云端账号服务。

## Verification

- `swift run ZikiCoreTestHarness`: 90/90.
- `swift run ZikiAppTestHarness`: 14/14.
- `swift scripts/verify-brand.swift`: source/icon correspondence, dimensions, neutral palette, template alpha, stable bundle identity.
- Native smoke checks: page selection and matching title, light/dark appearance, minimum window size, scrolling, empty history, configuration field states, and disabled updates in the isolated development bundle.
- The development bundle has separate storage and credentials. Launch with `--ui-dark` for per-app dark appearance in debug builds; this does not change system appearance.
- Provider/audio code and cleanup prompts were not changed. These checks do not claim a new live-model accuracy evaluation.
