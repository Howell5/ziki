# Ziki v0.5.0

2026-09-12 · Build 19 · Apple Silicon · macOS 13+

- 产品正式更名为 **Ziki**。应用、DMG／ZIP、菜单、设置、权限文案、Swift 模块和更新助手统一使用新名。
- GitHub 仓库迁移为 [Howell5/ziki](https://github.com/Howell5/ziki)，应用内更新与文档链接同步切换。
- 全新深松绿／暖白双弦 Z 图标，寓意子期与知音；Dock、关于页面和菜单栏标识同步更新。
- 听写、上下文整理、历史、诊断和录音自动静音行为不变。保留既有签名身份、密钥、配置及数据目录。

## 安装与升级

本版不提供 Sotto 旧名兼容包。旧版更新器无法自动升级到新包名：请先退出并移走旧应用，再将 DMG 内的 **Ziki.app** 拖入 Applications；不要同时运行新旧两份应用。以后可在 Ziki 的「设置 → 关于」继续检查并安装更新。

仍使用固定本地自签名证书，未经过 Apple Developer ID 签名或公证。应用身份不变，但 macOS 可能因路径／可执行文件改名要求重新确认权限。请按系统提示操作，不关闭系统安全检查。

资产：`Ziki-0.5.0-macOS-arm64.dmg`、`Ziki-0.5.0-macOS-arm64.zip`、`SHA256SUMS.txt`。
