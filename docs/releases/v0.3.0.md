# Sotto v0.3.0

2026-09-07 · Build 17 · Apple Silicon · macOS 13+

## 本次更新

- 删除 `protectedTokenChanged` 正则审核和字数比例否决。正常完成的模型结果直接交付，不再因 `Base 64 → Base64` 等变化退回整段原始转写。
- 同一次千问请求负责理解语境、纠正识别错误、去除口癖和整理结构；保留具体技术概念、问题、否定和不确定语气。没有增加第二次审核或摘要请求。
- 新增可关闭的近期听写上下文：最多 3 轮、合计 8000 字，默认仅暂存在内存。切换听写目标应用、间隔 10 分钟、清空或重启后不再沿用；菜单栏与语音设置均可“开始新对话”。不读取聊天窗口或 AI 回复，不恢复历史，不做长期记忆。
- 上下文会随整理请求发送至同一百炼 Workspace；不是纯本地处理。同一应用不等于同一聊天，在同一应用切换对话时建议手动清空。
- 请求失败、空响应或未完成输出仍保留原始转写。诊断模式额外记录实际使用的上下文、模型和 prompt 版本，继续按 7 天保留。

## 验证

- 核心测试 90/90、应用测试 10/10，通过完整编译。
- 6/6 真实千问整理样例通过，并人工复核输出：包含用户报告的长段转写、P1／正则恢复、日常“一阵子”、有效 PE 术语、金额／邮箱／链接、编号任务和不可信上下文。
- 真实评测复用生产请求构造及整理调用；不启用麦克风。样例通过不代表模型永远不会误改，重要数字等仍需核对。

## 安装与更新

已有 v0.2.14 的用户，可在 **设置 → 关于 → 检查更新** 后自行点击更新；应用验证下载包后退出并替换，完成后请手动重新打开。

新安装请下载 DMG 并拖入 Applications。继续使用同一固定本地自签名身份，未经过 Apple Developer ID 签名或公证；不要全局关闭 Gatekeeper。

资产包含 DMG、供应用内更新使用的 ZIP，以及 `SHA256SUMS.txt`。
