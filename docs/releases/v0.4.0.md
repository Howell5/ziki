# Sotto v0.4.0

2026-09-12 · Build 18 · Apple Silicon · macOS 13+

## 录音时自动静音

- 进入录音前临时静音当前系统输出；音乐和视频继续播放，不暂停、不修改音量值。
- 麦克风停止后立即恢复声音，不等待转写或千问整理。取消、启动失败和正常退出共用恢复路径，原本已静音的设备保持静音。
- 默认开启，可在「语音 → 录音时静音系统声音」关闭。经过当前输出设备的通知声也会静音。
- 切换默认输出设备时先静音新设备，再恢复旧设备；仅支持设备级可写静音开关，不支持的设备会提示手动操作，不阻止录音。
- 恢复失败、设备断开或强制退出后保留按设备 UID 标识的恢复记录；菜单栏和语音设置提供手动恢复入口。强制退出无法即时恢复，下次启动不会擅自开声。

## 验证与边界

- 核心 90 项、应用 14 项测试通过；本机真实静音／恢复测试通过，音量值保持不变。设备切换、写入失败和断线恢复通过模拟测试。
- 只控制当前系统输出，不控制单独路由到其他设备的播放器；没有系统音频采集或额外云端调用。
- 用户主动解除静音不会被持续强制静音，音量调整不会被覆盖；当前恢复按结束时静音状态判断，不能区分“解除后又重新静音”的用户操作。
