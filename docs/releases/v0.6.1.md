# Ziki 0.6.1 — New Bailian Models

## English

- Real-time dictation now uses Alibaba Cloud Model Studio's recommended `qwen-audio-3.0-asr-flash-streaming` model.
- Text cleanup now uses the fixed `qwen3.7-flash-2026-07-15` snapshot with thinking disabled, preserving Ziki's fast and conservative rewrite behavior.
- Existing Bailian region, Workspace ID, API Key, Keychain entry, and local settings continue to work. No credential migration is required.
- Model names and privacy disclosures in the app, README, and website now match the actual processing path.

The WebSocket protocol and regional endpoints are unchanged. This remains an Apple Silicon, self-signed preview and is not Apple-notarized. No subscription or cloud account service is included.
