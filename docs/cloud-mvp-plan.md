## 外部决策门槛

这些事项不阻塞安全的本地基础工作，但在相应阶段必须解决：

- P1：认证实现与必要身份/邮件供应商配置，原生登录安全路径。
- P2：官方模型账户、区域和授权测试预算；禁止自动上传个人 BYOK Key。
- P3：安全配置 Stripe 测试凭证、测试 Price ID；最终价格未定时只用明确标记的测试 fixture。
- P4：月费/额度/试用/加量有效期/部分成功计费，许可证与公私有边界，隐私/税务条款、正式签名公证、真实收费授权。
