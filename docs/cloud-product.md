# Ziki Cloud：产品文档

状态：初稿，待评审。阶段与证据只维护在 [执行计划](cloud-mvp-plan.md)。

## 定位与范围

海外个人用户优先，英文默认、中文保留；英国 Stripe 商户，用户以 USD 购买服务。最终银行结算币种另行核验。
一个原生 macOS App，两种明确选择：独立 BYOK，或登录使用官方 Cloud。商业价值是免配置与服务保障，不是删掉免费版基本能力。

MVP 包含：登录/退出/设备会话撤销、有限试用、一个月订阅、主动加量、用量查询、托管识别与整理、自助订阅管理、必要帮助与账号删除路径。
保留原有 Fn、录音静音、上下文、历史和文字插入。
不包含：团队、年付、多币种、无限量、会议机器人、小时级会议录音、云端全文历史/记忆同步、任意模型代理。
现有供应商的 3/5 分钟单次录音边界不会因为增加账号而自动取消。

## 使用规则

| 项目 | BYOK | Cloud |
|---|---|---|
| 账号 | 不需要 | 需要 |
| Key | 本机 Keychain | 官方供应商凭证仅在服务器 |
| 调用路径 | 客户端直连供应商 | Ziki 服务端鉴权、计量、调用 |
| 费用 | 用户自行支付供应商 | 订阅额度与主动购买加量 |
| 本地历史和核心功能 | 完整保留 | 完整保留 |

旧用户升级后保留模式与隐私设置。退出、到期或 Cloud 故障不锁本地历史，不自动改用个人 Key 扣费。
BYOK 不等于离线识别；Cloud 不等于默认同步历史。

主要流程：

- 新 Cloud 用户：安装 → 必要权限 → 浏览器登录 → 试用 → Fn 口述 → 整理并插入 → 看到用量。
- BYOK：选择自带 Key → 配置供应商 → 口述，全程不要求 Ziki 账号服务可用。
- 购买：登录 → USD 套餐 → Stripe Checkout → 服务端确认 → 刷新权益；返回页面不自行解锁。
- 不足/到期：提前提示购买、管理订阅或主动切换 BYOK，不丢弃已有结果。
- 取消：提议当期结束停止续费；账号删除和本地历史删除必须分开说明。

## 用量与失败

- 用户看分钟，内部按秒累计；常规文字整理包含在语音用量中。
- 先预留、后结算；系统重试不重复扣费，失败释放未消费预留。
- 不自动超额收费；开始前用剩余额度确定会话边界，到边界时完成已有结果，不提供无界免费宽限。
- 识别成功但整理失败：返回原始转写并提示；如何扣费/补偿尚需确认。
- 按订阅账期发额度，不按设备月份重置；退款和加量有效期规则必须明确。
- 未批准：价格、试用额度/期限、月度额度、加量价格/期限、部分成功计费和退款细则。30/600 分钟只是讨论假设。

## 开源与隐私

BYOK 核心能力保持完整公开，不故意增加配置障碍；应用许可证及云端代码开放范围待确认，不静默变更许可。
本地历史、词典与上下文默认在本机；Cloud 只发送处理所需音频、文字及有界上下文。
服务器默认保存用量和运行元数据，不保存正文与录音；诊断上传需明确授权和保留期限。

## 产品验收

1. 无账号完成 BYOK，Ziki 后端全部不可用时仍能使用。
2. 新用户无需供应商 Key 完成真实 Cloud 口述，额度与结果一致。
3. 支付、续费、取消、额度耗尽状态与服务端一致，不影响本地数据。
4. 整理失败可恢复；英文主流程无意外中文提示。
5. 观察首次成功耗时、会话成功率、完成延迟、单位成本与留存，不为统计采集正文。
